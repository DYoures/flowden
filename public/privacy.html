Privacy Policy

Application: Flowden Digital Workspace Version: 1.0.0 Status: Operational Draft

1. Scope and Product Architecture

Flowden is a digital spatial productivity workspace designed to help users capture ideas, organize structured knowledge, visualize connections, track workflows, and catalog research literature.

This Privacy Policy accurately documents how Flowden collects, processes, and protects your information across the web application and its localized APIs.

2. Information Collected and Stored

Flowden collects only the data required to operate workspace features and preserve your information. We do not engage in behavioral advertising, third-party user tracking, or third-party data broker sales.

Account and Profile Information

  • Email Address: Used as your unique account identifier for authentication and service communications.
  • Password Hash: Stored strictly as a cryptographically salted one-way hash using bcrypt. Plaintext passwords are never logged or stored.
  • Display Name: Used to personalize your workspace header and activity timestamps.
  • User Interface Preferences: Theme selection (dark or light mode) and sidebar state preferences.

Workspace and Knowledge Content

  • Projects and Spatial Boards: Project titles, descriptions, card items (notes, ideas, links, references), coordinates, dimensions, colors, and connection lines.
  • Knowledge Vault Notes: Note titles, markdown content, tags, folder organization, bi-directional wiki-link maps, and automatic version snapshots.
  • Workflow Tracker: Tasks, priorities, due dates, status lifecycle states, and completion timestamps.
  • Architectural Decision Records: Decision context, decisions made, outcomes, and decision dates.
  • Quick Captures: Inbox captures and processing state.

Research Documents and Uploads

  • Uploaded Files: Documents uploaded to the Research Center (.md, .pdf, .docx, .txt) are stored directly on the server filesystem in the protected uploads directory.
  • Extracted Content: Plaintext extracted from imported documents, source citation URLs, and generated research summaries are stored in the database.

Session and Technical Data

  • Authentication Cookies: Secure, httpOnly JSON Web Token (JWT) cookies used to maintain your authenticated session.
  • Server Access Logs: Standard web server request logs (IP address, user agent, request timestamp, and route) retained temporarily for diagnostic and security auditing purposes.

3. Local Processing and Model Context Protocol (MCP)

Flowden includes support for the Model Context Protocol (MCP), providing a standard interface for external AI assistants (such as Claude Desktop or command-line developer agents) to query workspace knowledge.

  • Explicit Token Authentication: MCP endpoints require explicit Bearer token authorization configured by the user.
  • Tenant Boundary: MCP queries are strictly bound to the authenticated user's workspace items and cannot query other users' data.
  • No Silent Third-Party Transmission: Flowden does not send your notes or documents to external LLM providers unless you explicitly configure and run an external MCP client.

4. Data Isolation and Security

Flowden implements technical safeguards to protect your workspace content:

  • Strict tenant data isolation enforcing user ownership across all database queries.
  • Role-based access control distinguishing administrative diagnostic routes from standard user workspaces.
  • Secure HTTP headers configured through Helmet, including Content Security Policy, X-Content-Type-Options, and frameguard protections.

5. Data Ownership, Portability, and Deletion

You retain full ownership of all content created or uploaded in Flowden:

  • Full Workspace Export: You can download a complete, portable JSON archive of your entire workspace (projects, boards, notes, tasks, research records, and decisions) at any time from Settings.
  • Markdown Note Export: Individual notes can be exported as standard markdown files directly from the Knowledge Vault.
  • Content Deletion: Deleting notes, tasks, research documents, or projects removes them from the primary database and related filesystem storage.
